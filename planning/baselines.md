# Baselines

Competitor systems used for head-to-head comparison against JalRakshak's offline-first edge architecture (Slide 9):
- **Baseline A (Cloud-Dependent Pipeline, Ali et al. [6]):** Nodes stream raw/periodic readings; water-quality, leakage, and abnormal-consumption detection run remotely in the cloud/server.
- **Baseline B (Single-Task Edge Approaches, Papers [1, 2, 3, 5]):** Isolated single-purpose edge detectors evaluated individually.
